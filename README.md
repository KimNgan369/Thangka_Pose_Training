# Thangka Pose Training

Research code and development notes for the Thangka pose training project.

The main pipeline is in `Thangka_Pose_Training.ipynb`. Development notes are in `reports/development/`. Source scripts from quality experiments live under `outputs/quality_v2/` and are tracked explicitly.

The local `data/`, `cache/`, `ratings/`, `pretrained/`, and generated `outputs/` artifacts are excluded from Git. The dataset card states that the images and manifests are for internal research and must not be published. To run the notebook, obtain the authorized dataset and model files separately and place them at the paths expected by the notebook.
