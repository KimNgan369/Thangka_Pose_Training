# Thangka Pose Training

Full local archive of the Thangka pose training project, including source code, research data, model artifacts, and run outputs.

The main pipeline is in `Thangka_Pose_Training.ipynb`. Source scripts from quality experiments live under `outputs/quality_v2/`.

The dataset card states that images and manifests are for internal research and prohibit public release. Keep any remote repository private and restrict access to authorized collaborators.
